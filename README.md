# 🧩 Multiplayer Web Scrabble
A fully functional, browser-based Scrabble clone featuring automated scoring and dictionary validation.
https://nour-mistrah.github.io/Scrabble-Game/

## 🚀 Features
* Multiplayer: Supports 1-4 players.
* Dictionary Validation: Uses the Free Dictionary API to verify words.
* Scoring: Automatically calculates Double/Triple letters and words.
* Bingo Bonus: +50 points for using all 7 tiles.

## 🛠️ How to Play
1. Open index.html in any modern browser.
2. Select the number of players.
3. Drag tiles from your rack to the board.
4. Words must start on the Star and connect to existing tiles thereafter.
5. Click Submit to finalize your turn.

## 💻 Tech Stack
* HTML5 / CSS3 (Grid and Flexbox)
* JavaScript (ES6+, Async/Await for API calls)
